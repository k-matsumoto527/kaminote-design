# かみのて保育園サイト｜トップページ デザイン案

株式会社 A and K さま向け。提案書（`~/kaminote-proposal`）の **04 次のステップ**で約束した
「トップページを1枚だけ先にお作りし、方向性をご確認いただく」ためのもの。

- 実体は `index.html` 1枚のみ。ビルド不要でそのまま開ける。
- 画像は `img/hero.jpg`（提案書の表紙と同じ写真を流用）。

## 構成

提案書 02節「画面イメージ」の保育園サイト トップの11ブロックを、そのままの順で実装している。
**構成は提案書と一致させること。**ここでずらすと「間取りは決まった」という前提が崩れる。

1. ヘッダー（ロゴ／ナビ／見学CTA）
2. ヒーロー（見出し・写真）
3. 帯（開園時間・施設数・対応言語）※提案書には無い追加分
4. 選ばれている3つの理由
5. かみのての保育 ― 大切にしていること
6. 園のご紹介（かみのて保育園／かみのて今渡保育園）
7. 病児保育のご案内 → 専用ページ
8. 入園案内・保育料（企業主導型／提携企業）
9. かみのてで働く人 → 採用ページ
10. お知らせ・園の日記
11. 見学・お問い合わせ／フッター

## デザインの意図

- **深い緑（#2f6b4f）＝安心・信頼**、**山吹（#e8a33d）＝子どもの明るさ**。
  ヒーロー写真の木の色・紙の色に合わせて選んでいる。
- 見出しは丸ゴシック（Zen Maru Gothic）、本文は Noto Sans JP。
  やわらかさは見出しだけで出し、本文は読みやすさを優先している。
  保育園らしさを出しつつ、法人としての信頼感を損なわないための配分。
- 「かわいい」に寄せすぎない。株式会社 A and K は外国人材事業も持つ法人で、
  会社案内ページから流入する読み手もいるため。

## 仮の情報（取材で必ず差し替える）

住所・対象年齢・定員・電話番号・お知らせの見出し・すべての写真。
`.ph`（斜線の枠）が写真の入る場所で、枠内に何を撮るかを書いてある。
ページ最上部の黒い帯（`.demobar`）でその旨を明示している。**納品時は削除する。**

## 確認済みの表示

Edge ヘッドレスで検証。横スクロールは 390 / 489 / 768 / 1200px すべてで発生なし。
390px は Edge の最小ウィンドウ幅（約477px）に丸められるため、
390px 幅の `<iframe>` に入れて内側から `scrollWidth` を測っている。

`.reason` はスマホで「アイコン＋本文」の横並びにするが、
見出しと本文を `.reason-body` でくくらないと2カラムグリッドの別セルに落ちて
はみ出す。まとめてあるのはそのため。
