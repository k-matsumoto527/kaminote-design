# かみのて保育園サイト｜トップページ デザイン案

株式会社 A and K さま向け。提案書（`~/kaminote-proposal`）の **04 次のステップ**で約束した
「トップページを1枚だけ先にお作りし、方向性をご確認いただく」ためのもの。

- 実体は `index.html` 1枚のみ。ビルド不要でそのまま開ける。
- 画像は `img/` 配下（内訳は後述の「写真」を参照）。
- 公開先: https://k-matsumoto527.github.io/kaminote-design/

## 前提（2026-08-02 確定）

提案書を送付した結果、**2サイト案に決定**した。
つまり「保育園サイト」＋「放課後等デイサイト（かみのてKIDS・かみのてSMILEを1つに）」の2本。

このデザイン案は保育園サイトのトップで、**2サイト案でも中身は変わらない**
（提案書で2サイト案の保育園サイトは「※A案と同じ」と明記していたため）。
ただし**フッターの「グループの事業」は3サイト案前提で書いていたので修正済み**。
KIDSとSMILEを別サイトとして並べるのではなく、「放課後等デイサービス」1本にし、
その下に2事業所名を小さく添えている。**ここを3サイト案の書き方に戻さないこと。**

## 構成

提案書 02節「画面イメージ」の保育園サイト トップの11ブロックを、そのままの順で実装している。
**構成は提案書と一致させること。**ここでずらすと「間取りは決まった」という前提が崩れる。

1. ヘッダー（ロゴ／ナビ／見学CTA）
2. ヒーロー（見出し・写真）
3. 帯（開園時間・施設数・対応言語）※提案書には無い追加分
4. 選ばれている3つの理由
5. かみのての保育 ― 大切にしていること
6. 園のご紹介（かみのて保育園／かみのて今渡保育園）
7. 病児保育のご案内 → 専用ページ
8. 入園案内・保育料（企業主導型／提携企業）
9. かみのてで働く人 → 採用ページ
10. お知らせ・園の日記
11. 見学・お問い合わせ／フッター

ナビとフッターは、提案書の**保育園サイト ページ一覧（全11ページ）すべてに導線がある**状態に
してある。「私たちについて」と「園での生活」はトップに対応するブロックが無い独立ページなので、
リンクだけ置いている（`href="#"`）。
**セクションラベルに「わたしたちについて」を使ってはいけない。**
提案書では「私たちについて」が別の独立ページ（理念・園長メッセージ・法人概要）なので、
4番目のブロックのラベルは「かみのての保育」にすること。

ナビは6項目あり、ロゴとCTAを合わせると約1040pxを切ると一列に入らない。
折り返すと崩れるので、`@media (max-width:1040px)` でメニューごと畳んでいる。
**この崩れは `scrollWidth` の検査では出ない**（折り返しははみ出しではないため）。
ヘッダーは幅を変えて目視すること。

## デザインの意図

### 色（2026-08-02 変更）

**主色はアプリコット／オレンジ。** 放課後等デイサイトが顧客要望でパステルグリーンに
決まったため、当初のミント（#7fc6a0）のままだと2サイトが同じ色に見えてしまう。
**顧客要望で色が固定されているのは放デイ側なので、動かしたのは保育園サイト。**

- `--ap` #f2a765（面）／ `--ap-dark` #cf7a35（文字）／ `--ap-deep` #a85c2a（濃い面）
  ／ `--ap-soft` #fdeade（薄い面）／ `--hl` #ffe0b5（見出しのマーカー）
- **薄いアプリコットを文字色に使わないこと。**読めない。文字は `--ap-dark` 以上。
- 暖色一色になるのを避けるため、**病児保育と園の日記と提携企業カードだけ水色**
  （`--sky-soft` / `--sky-dark`）にしている。「別の用件」だと分かるようにするため。
- 採用パネルはボタンと同色だと沈むので、濃いテラコッタ（`--ap-deep`）。

**ミントに戻さないこと。**放デイサイトと見分けがつかなくなる。

### 共通の設計言語

**かみのてKIDSサンプル（`~/kids-support-sample`）とテイストを揃えている。**
放課後等デイサイト（`~/kaminote-day`）とも、色以外はすべて共通にしてある。
同じグループだと分かるようにするため。

- 書体は Zen Maru Gothic を全面に。英字は Baloo 2（`.en`）
- ヒーローは**写真を全面背景にしてクリームのグラデーションを重ねる**方式。
  中央寄せ・ピル型バッジ・見出しの一部にマーカー（`.hl`）・2行目を主色（`.warm`）
- ヒーロー下の波型SVG（`.wave`）で次のセクションへつなぐ
- セクションラベルは絵文字＋主色の小見出し、見出し下に英字（`.sec-title .en`）
- 丸いピル型ボタン、やわらかい影、大きめの角丸
- スクロールで要素がふわっと出る（`.reveal` ＋ IntersectionObserver）

`prefers-reduced-motion` を指定している人にはアニメーションを出さない。

**ヒーローに絵文字は入れない。** サンプルには浮遊する絵文字の飾り（🌷⭐🧸🎈）があり
一度は入れたが、指示により削除した。CTAボタンに付けていた 🌱 も同時に外している。
ヒーロー以外のセクションラベルの絵文字はそのまま残している。

## 写真

すべて Unsplash から取得したイメージ写真。
Unsplash License なので商用利用・改変可、クレジット表記は任意。
ただし**すべて取材時に園の実写へ差し替える前提**で、
借り物と分かるよう写真の左上に「イメージ写真」バッジ（`.photo .stock`）を出している。
**納品時はバッジごと削除する。**

| `hero.jpg` | 旧ヒーロー（未使用・差し戻し用に残置） | ユーザー提供（提案書の表紙と同じ） |

取得は `https://images.unsplash.com/photo-<id>?w=<幅>&q=78&fm=jpg&fit=crop`。
**検索API（api.unsplash.com / unsplash.com/napi）はキーが無いと401になる**ので、
候補IDを直接叩いて取得し、コンタクトシートに並べて目視で選んでいる。

**ヒーローを差し替えた理由**: 旧 `hero.jpg`（製作あそびの真上からの寄り）は、
全面背景にすると絵柄が細かく色数も多いため、上に乗る文字が読めなくなる。
オーバーレイを濃くすると今度は全体が白茶けてサンプルの軽さが失われた。
全面背景に耐える（低コントラストな面がある）写真に替えている。
**旧ヒーローに戻すなら `.hero` の `url('img/hero-field.jpg')` を `url('img/hero.jpg')` に戻すだけでよい。**

**採用情報のブロックには写真を入れていない。** 「保育士とこども」の使える写真が
Unsplash 側で見つからなかったため（候補は年代の古い米国の教室、小学校の風景、
文脈のないポートレートばかりだった）。数字タイルだけで成立しており、
テイストの元にした kids-support-sample もヒーロー以外に写真を使っていないので不整合はない。
**取材で職員の写真を撮ったら、ここに入れるのがいちばん効く。**

3つの理由・入園案内・お問い合わせも写真なし。絵文字と色面で構成しており、これは意図どおり。

**園舎の外観写真はあえて使っていない。** 実在する別の建物を「かみのて保育園」として
見せると誤解を招くため、園のようすの写真を当てている。

## 確認済みの表示

Edge ヘッドレスで検証。横スクロールは 390 / 489 / 768 / 1200px すべてで発生なし。
390px は Edge の最小ウィンドウ幅（約477px）に丸められるため、
390px 幅の `<iframe>` に入れて内側から `scrollWidth` を測っている。

`.reason` はスマホで「アイコン＋本文」の横並びにするが、
見出しと本文を `.reason-body` でくくらないと2カラムグリッドの別セルに落ちて
はみ出す。まとめてあるのはそのため。
